# Project NOVA 3D — Architecture

Project NOVA 3D is structured into four strictly separated layers per Section 10 of the Product Requirements Document:

## 1. Core Engine (`rust/nova_core`)
- **Responsibility:** Single source of truth for scene graph, mesh geometry, transforms, selection, gizmos, command-based undo/redo history, camera state, and `.nova3d` serialization.
- **Key modules:**
  - `math.rs`: Deterministic column-major `Mat4`, `Quat`, `Vec3`, inverse/decomposition helpers, and `Ray` intersection math (AABB, triangle Möller–Trumbore, plane, axis projection).
  - `primitives.rs`: Procedural triangle-mesh and helper builders for all 11 P0 object types (`Cube`, `UV Sphere`, `Icosphere`, `Cylinder`, `Cone`, `Torus`, `Plane`, `Circle`, `Empty`, `Camera`, `Light`).
  - `poly.rs`: Editable `PolyMesh` (`vertices`, `faces`, `smooth_shading`), tri-planar UV mapping, mesh editing operators (`extrude`, `inset`, `bevel`, `loop_cut`, `subdivide`, `merge_selected`, `delete_selected`, `dissolve_edges`, normal flip/recalc), and non-destructive modifier evaluator (`Mirror`, `Subdivision`, `Solidify`, `Array`).
  - `lookdev.rs`: PBR `MaterialSpec` (opacity/alpha blend, metallic, roughness, normal/AO/emissive maps, UV tiling), 8 built-in presets, `TextureAsset` + 7 procedural RGBA textures + missing-texture checker fallback + base64 helpers, and `EnvironmentSpec` (6 HDR IBL presets, rotation, exposure, skybox, bloom).
  - `camera.rs`: Orbit/pan/zoom camera, perspective & orthographic projections, standard views, bounds framing.
  - `scene.rs`: `NovaEngineState`, `SceneNode` hierarchy (`parent_id`, `base_poly`, `modifiers`, `material_id`, `mesh_version`, materials, textures, lights, environment, `material_preview_sphere`), `Object` <-> `Edit` interaction modes, 4 viewport shading modes, element/node ray picking, World/Local 3D gizmo drag math, transform baking/origin recentering, Studio Lighting Rigs, and world bounds.
  - `command.rs`: `Command` trait and `CommandHistory` for undoable/redoable scene, hierarchy, transform, poly-mesh, modifier stack, material, texture, lighting rig, environment, and light edits.
  - `serialize.rs`: Zero-dependency `.nova3d` v1 JSON serializer and validating recursive-descent parser (including `poly`, `modifiers`, Material Library, embedded base64 textures, animation timeline/tracks, and HDR environment with M2/M3 backward compatibility).
  - `animation.rs`: Deterministic timeline (`TimelineSettings`), 23 `AnimChannelKind` keyframe channels (`Node`/`Material`, `Bone` extension point), 6 interpolation modes (`Linear`, `Constant`, `Bezier`, `EaseIn`, `EaseOut`, `EaseInOut`), and `.nova3d` persistence.
  - `io_formats.rs`: Dependency-free 3D exchange importer/exporter supporting Wavefront `.obj` and glTF 2.0 `.gltf`/`.glb` (hierarchy TRS/matrix, UV V-flip, missing-normal generation, fan triangulation, PBR metallic-roughness materials, pure-Rust CRC32/Adler32/RFC-1951 DEFLATE PNG codec, `64 MiB`/`1M` vertex bounds, and thread-local `FM-7` conversion warnings).
  - `error.rs` & `ffi.rs`: Thread-local structured error propagation, monotonic `replace_scene_state` revision/version guards, and panic-safe C-ABI (`nova_core_*`) matching `native/include/nova_core.h`.

## 2. Rendering Layer (`native/renderer`)
- **Responsibility:** Consumes derived scene/camera snapshots from the Rust core and drives GPU rendering.
- **Abstraction:** `RenderBackend` (`native/renderer/render_backend.h`) isolates Filament behind an abstract interface so alternative backends (such as a future offline path tracer) can be added without modifying the core or UI.
- **Filament Implementation (`filament_backend.cpp`):**
  - Automatic capability detection: attempts `Engine::Backend::VULKAN` first and falls back to `Engine::Backend::OPENGL` (OpenGL ES 3.0+).
  - Compiles opaque & transparent multi-texture PBR (`NovaDefaultPBR`, `NovaTransparentPBR` with 5 texture samplers + IEC sRGB-to-linear conversion), unlit world-grid line, translucent overlay triangle (`translucentTriMaterial_`, `BlendingMode::TRANSPARENT`), and depth-disabled overlay line (`depthWrite(false)`, `depthCulling(false)`, priority `7`) materials via `filamat::MaterialBuilder`.
  - Manages procedural `RGBA16F` IBL reflection cubemap pyramids + 3-band SH irradiance, rotating `Skybox`, `BloomOptions`, camera exposure, mipmapped GPU texture cache (including missing-texture checker fallback), isolated Shaderball Preview Sphere, dynamic wireframe overlay (`shading_mode == 1`), Edit Mode wireframe/vertex (`editLineEntity_`) and translucent face overlays (`editTriEntity_`), dynamic `Point`/`Directional`/`Spot` lights, selection bounding boxes, helper icons, and 3D `Move` / `Rotate` / `Scale` gizmos.
  - **Layer Separation & Offscreen Pipeline (M6):** Editor-only helpers (`gridEntity_`, `axesEntity_`, `overlayEntity_`, `editLineEntity_`, `editTriEntity_`, `wireframeEntity_`, `previewSphereEntity_`) reside on visibility layer `1` (`0x02`), while scene geometry resides on layer `0` (`0x01`). `offscreenView_` uses layer mask `(0x03, 0x01)` to guarantee clean final renders without viewport overlays. `RenderQualityConfig` drives `applyQualityToView` (FXAA + 4x MSAA, SSAO/GTAO, Bloom, Depth of Field + focus distance, HDR color buffer, PCSS/PCF/VSM shadows, ACES/Filmic/PBRNeutral tone mapping, and adaptive dynamic resolution). Still renders capture via `SwapChain::CONFIG_READABLE` + `renderer_->readPixels` (preserving top-down Vulkan order and flipping OpenGL ES bottom-up rows); video encodes render directly into an `ANativeWindow` backed by `MediaCodec::createInputSurface()`.

## 3. Native Bridge (`native/bridge/nova_jni.cpp` + `NovaNativeBridge.kt`)
- **Responsibility:** Narrow JNI boundary managing thread-safe `NovaSession` (`std::mutex` + `NovaCoreHandle*` + `RenderBackend`).
- Handles `ANativeWindow` lifecycle (`attachSurface`, `resizeSurface`, `detachSurface`), offscreen still readback (`nativeRenderStillRgba`), `MediaCodec` video `Surface` lifecycle (`nativeBeginVideoSurface`, `nativeRenderVideoFrame`, `nativeEndVideoSurface`), adaptive viewport quality toggle, `.glb`/`.gltf`/`.obj` import/export byte buffers + conversion warnings, and all scene/modeling/look-dev/animation edits.

## 4. Android UI & Storage (`android/app/src/main/java/com/nova3d/studio`)
- **Responsibility:** Kotlin + Jetpack Compose dark workspace shell, `Home`, `Projects`, `Workspace`, `Materials` (`MaterialsScreen.kt`), `Animation` (`AnimationScreen.kt`), `Render` (`RenderScreen.kt`), and `Settings` screens, tabbed `Outliner`, `Properties`, and `World` inspector, responsive layout, and `NovaRenderThread` + `Choreographer` frame presentation.
- **Offscreen Render & Video Pipeline (`render/OffscreenRenderEngine.kt`):** Marshals Filament offscreen calls onto `NovaRenderThread`, probes device free RAM & hardware H.264 encoder limits (`RN-7` safe downscale before OOM/codec failure), writes lossless PNG / 95% JPEG stills, encodes MP4 (`H.264` + `MediaMuxer`) frame-by-frame with cancel support, and manages gallery storage, SAF device export, and `FileProvider` sharing (`${applicationId}.fileprovider`).
- **Transactional Storage (`storage/ProjectStorage.kt`):** Runs all disk/SAF/image decoding I/O on `Dispatchers.IO` using temp-file + `fsync` + atomic move, captures `PixelCopy` viewport PNG thumbnails, and maintains debounced background + pause autosave with crash recovery prompts on launch.
- **Principle 1 Compliance (v1.0 Complete):** All top-level workspaces (`Home`, `Projects`, `Workspace`, `Materials`, `Animation`, `Render`, `Settings`) are fully wired and functional end-to-end; all pending milestone markers are retired for v1.0.
